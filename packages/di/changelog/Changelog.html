[0.1.0] — 2026-11-22

Added

  • Declarative Service Lifetime Attributes: Custom compile-time attributes ([Singleton], [Scoped], [Transient]) enabling automatic service discovery and registration without manual services.Add... boilerplate.
  • Assembly Scanning & Auto-Registration: Reflection and type scanning engine searching assemblies, namespaces, and implementation types, matching interface conventions automatically.
  • Keyed Services Support: Full integration with .NET 8+ keyed dependency injection ([KeyedService], [FromKeyedServices]), enabling clean multi-tenant and multi-strategy resolution.
  • Modular Architecture (IDixorModule): Extensible module interface allowing domain-driven architecture and feature libraries to encapsulate their own DI container definitions.
  • Ambient Context Flow (AmbientContext<T>): Thread-safe async-local context carrier enabling scoped ambient dependencies without constructor pollution across deep call stacks.
  • External JSON & XML Configuration: Configuration-driven dependency bindings enabling runtime service override from appsettings.json or XML declarations without recompilation.
  • Unified Ecosystem Bootstrapping: 1-line root registration method builder.Services.AddDixor() bootstrapping Dixor.DI, Dixor.Identity, Dixor.Security, and Dixor.Validation in a single fluent call.
