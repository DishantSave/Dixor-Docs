Dependency Injection & Consumption Patterns

Dixor.DI provides flexible, ergonomic patterns for injecting and consuming services across your application.

1. Standard Constructor Injection

The standard way to consume dependencies in .NET classes:

public class OrderService : IOrderService
{
    private readonly IOrderRepository _repository;
    private readonly IEmailValidatorService _emailValidator;

    public OrderService(IOrderRepository repository, IEmailValidatorService emailValidator)
    {
        _repository = repository;
        _emailValidator = emailValidator;
    }

    public async Task CreateOrderAsync(CreateOrderDto dto)
    {
        if (!_emailValidator.Validate(dto.CustomerEmail).IsValid)
            throw new ArgumentException("Invalid customer email");

        await _repository.SaveAsync(dto);
    }
}

2. Modern C# 12+ Primary Constructors

Clean, concise dependency injection without private field assignments:

[Scoped]
public class CustomerService(
    ICustomerRepository repository,
    IUuid7Service uuid7,
    IPhoneValidatorService phoneValidator) : ICustomerService
{
    public Customer Create(string name, string phone)
    {
        if (!phoneValidator.Validate(phone).IsValid)
            throw new ArgumentException("Invalid phone number");

        var customer = new Customer(uuid7.NewGuid(), name, phone);
        return repository.Insert(customer);
    }
}

3. Keyed Service Injection ([FromKeyedServices])

When multiple implementations of an interface are registered with unique keys (e.g., "stripe", "paypal"), inject a specific one directly using the native .NET [FromKeyedServices] attribute:

public class CheckoutController : ControllerBase
{
    private readonly IPaymentGateway _stripeGateway;
    private readonly IPaymentGateway _paypalGateway;

    public CheckoutController(
        [FromKeyedServices("stripe")] IPaymentGateway stripeGateway,
        [FromKeyedServices("paypal")] IPaymentGateway paypalGateway)
    {
        _stripeGateway = stripeGateway;
        _paypalGateway = paypalGateway;
    }

    [HttpPost("pay/card")]
    public async Task<IActionResult> PayWithCard([FromBody] CardPaymentRequest req)
    {
        var result = await _stripeGateway.ProcessPaymentAsync(req.Amount);
        return Ok(result);
    }
}

4. Dynamic Selection with IDixorResolver<TService>

If the target implementation is chosen dynamically at runtime (for example, based on user input or tenant preference), inject IDixorResolver<TService>:

[Scoped]
public class PaymentOrchestrator(IDixorResolver<IPaymentGateway> gatewayResolver)
{
    public async Task<PaymentResult> ProcessAsync(string providerKey, decimal amount)
    {
        // Dynamically resolve: "stripe", "paypal", "razorpay"
        IPaymentGateway gateway = gatewayResolver.ResolveRequired(providerKey);

        return await gateway.ProcessPaymentAsync(amount);
    }

    public IPaymentGateway GetDefaultGateway()
    {
        // Resolves the implementation marked with [PrimaryService]
        return gatewayResolver.GetDefault() 
            ?? throw new InvalidOperationException("No default payment gateway configured.");
    }
}

5. Collection Injection (IEnumerable<TService>)

When you need to execute all registered implementations of a contract (e.g., running a suite of validation rules or notification channels):

[Scoped]
public class NotificationBroadcaster(IEnumerable<INotificationChannel> channels)
{
    public async Task BroadcastAsync(string message)
    {
        foreach (var channel in channels)
        {
            await channel.SendAsync(message);
        }
    }
}

6. Parameterized Activation (IDixorFactory<TService, TArg>)

When you have a service that requires both container dependencies (loggers, repositories) and dynamic runtime arguments (e.g. orderId, sessionId) passed by the caller:

// Definition:
public class OrderWorker(ILogger<OrderWorker> logger, IOrderRepository repo, string orderId)
{
    public void Execute() => logger.LogInformation("Processing order {Id}", orderId);
}

// Registration in Program.cs:
builder.Services.AddDixorParameterizedFactory<OrderWorker, string>();

// Consumption:
public class OrderDispatcher(IDixorFactory<OrderWorker, string> workerFactory)
{
    public void Dispatch(string orderId)
    {
        // DI container injects logger & repo automatically; orderId is supplied dynamically!
        OrderWorker worker = workerFactory.Create(orderId);
        worker.Execute();
    }
}
