Declarative Attributes Reference

Dixor.DI provides attributes to define dependency injection behaviors directly at the class declaration level.

1. [ServiceAttribute]

The base attribute for all declarative registrations.

[Service(ServiceLifetime lifetime, Type? As = null, object? Key = null, bool TryAdd = false)]

Properties

Property Type Default Description
Lifetime ServiceLifetime (Required) Container lifetime: Singleton, Scoped, or Transient.
As Type? null The abstraction/interface contract to register as. If omitted, all implemented interfaces are registered.
Key object? null Optional key for registering keyed services (.NET 8+).
TryAdd bool false When true, does not register if a descriptor for the service type already exists.

Example

[Service(ServiceLifetime.Singleton, As = typeof(IStorageService), Key = "aws-s3")]
public class S3StorageService : IStorageService
{
    // ...
}

2. Convenience Lifetime Attributes

To make declarations even cleaner, Dixor.DI includes strongly typed shortcuts:

[Singleton]

Equivalent to [Service(ServiceLifetime.Singleton)]:

[Singleton]
public class CacheService : ICacheService { }

[Singleton(TryAdd = true)]
public class FallbackLogger : ILogger { }

[Scoped]

Equivalent to [Service(ServiceLifetime.Scoped)]:

[Scoped]
public class CustomerService : ICustomerService { }

[Scoped(As = typeof(IUnitOfWork))]
public class AppDbContext : DbContext, IUnitOfWork { }

[Transient]

Equivalent to [Service(ServiceLifetime.Transient)]:

[Transient]
public class EmailDispatcher : IEmailDispatcher { }

Interface Auto-Mapping Rules

When As is not explicitly declared:

  1. Multiple Interfaces: 
    [Scoped]
public class OrderProcessor : IOrderProcessor, IAuditRecorder
{
    // Resolvable via both IOrderProcessor and IAuditRecorder!
}
  2. No Interfaces (Self-Registration): 
    [Singleton]
public class MemoryPool
{
    // Resolvable directly via provider.GetRequiredService<MemoryPool>()!
}
  3. Ignored Interfaces: Common framework interfaces like IDisposable and IAsyncDisposable are excluded from registration contracts automatically.
