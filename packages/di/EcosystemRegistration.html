Ecosystem 1-Line Bootstrapping

Dixor.DI makes using the entire Dixor ecosystem (Dixor.Identity and Dixor.Validation) effortless.

1-Line Full Ecosystem Registration

With a single method call in Program.cs, you register:

  1. All Dixor.Identity services.
  2. All Dixor.Validation services.
  3. All declarative [Service] classes in your application assembly.
// In Program.cs
var builder = WebApplication.CreateBuilder(args);

// Register everything in 1 line:
builder.Services.AddDixor();

var app = builder.Build();

Granular Registration Extensions

If you prefer to register specific components independently:

1. services.AddDixorValidation()

Exposes all internal validation engines directly into IServiceCollection as singletons:

  • IEmailValidatorService
  • IPhoneValidatorService
  • IPassportValidatorService
  • IAddressValidatorService
  • IAadhaarValidatorService
  • ICreditCardValidatorService
  • IUrlValidatorService

2. services.AddDixorIdentity()

Exposes all internal identity generation engines directly into IServiceCollection as singletons:

  • IUuid7Service
  • IUlidService
  • IShortIdService
  • ISequenceFactory
  • INumericCodeService
  • INanoIdService
  • IHexadecimalService
  • IBase62Service
  • IBase36Service

3. services.AddDixorServices()

Scans the calling assembly (or specified assemblies) for declarative attributes:

builder.Services.AddDixorServices();
// Or with marker:
builder.Services.AddDixorServicesFrom<UserService>();

Constructor Injection Example

Once registered, inject any Dixor service directly into your controllers, endpoints, or services:

[ApiController]
[Route("api/users")]
public class UserController : ControllerBase
{
    private readonly IUuid7Service _uuid7;
    private readonly IEmailValidatorService _emailValidator;
    private readonly IPhoneValidatorService _phoneValidator;

    public UserController(
        IUuid7Service uuid7,
        IEmailValidatorService emailValidator,
        IPhoneValidatorService phoneValidator)
    {
        _uuid7 = uuid7;
        _emailValidator = emailValidator;
        _phoneValidator = phoneValidator;
    }

    [HttpPost("register")]
    public IActionResult Register([FromBody] UserRegistrationRequest request)
    {
        if (!_emailValidator.Validate(request.Email).IsValid)
            return BadRequest("Invalid email address.");

        if (!_phoneValidator.Validate(request.Phone).IsValid)
            return BadRequest("Invalid phone number.");

        var userId = _uuid7.NewGuid();
        return Ok(new { UserId = userId, Status = "Created" });
    }
}
