Multiple Implementations per Interface

Enterprise architectures frequently require multiple implementations of the same contract:

  • Payment Processors: StripePaymentGateway, PayPalPaymentGateway, RazorpayPaymentGateway.
  • Storage Providers: AwsS3StorageProvider, AzureBlobStorageProvider, LocalStorageProvider.
  • Notification Channels: EmailNotification, SmsNotification, PushNotification.

Dixor.DI makes declaring, prioritizing, and resolving multiple implementations simple and robust.

1. Registering with Unique Keys

Annotate each implementation with a unique key:

[Service(ServiceLifetime.Scoped, Key = "stripe")]
public class StripePaymentGateway : IPaymentGateway
{
    public string Name => "Stripe";
}

[Service(ServiceLifetime.Scoped, Key = "paypal")]
public class PayPalPaymentGateway : IPaymentGateway
{
    public string Name => "PayPal";
}

[Service(ServiceLifetime.Scoped, Key = "razorpay")]
public class RazorpayPaymentGateway : IPaymentGateway
{
    public string Name => "Razorpay";
}

When scanned by services.AddDixor(), each service is registered under its key and as part of IEnumerable<IPaymentGateway>.

2. Designating a Default Implementation ([PrimaryService])

When consumers inject IPaymentGateway directly without a key, you can specify which implementation serves as the primary/default:

[Service(ServiceLifetime.Scoped, Key = "stripe"), PrimaryService]
public class StripePaymentGateway : IPaymentGateway
{
    // Designated as primary!
}
  • Standard Injection: public MyController(IPaymentGateway gateway) receives StripePaymentGateway.
  • Keyed Injection: public MyController([FromKeyedServices("paypal")] IPaymentGateway gateway) receives PayPalPaymentGateway.

3. Dynamic Runtime Resolution (IDixorResolver<TService>)

Inject IDixorResolver<TService> to dynamically choose implementations based on request headers, user settings, or database records:

public class CheckoutService(IDixorResolver<IPaymentGateway> gatewayResolver)
{
    public async Task ProcessAsync(string selectedGateway, decimal amount)
    {
        // 1. Resolve by key:
        IPaymentGateway gateway = gatewayResolver.Resolve(selectedGateway)
            ?? gatewayResolver.GetDefault()
            ?? throw new InvalidOperationException("Gateway unavailable.");

        await gateway.ChargeAsync(amount);
    }

    public IEnumerable<string> GetAvailableGateways()
    {
        // 2. Iterate all implementations:
        return gatewayResolver.All.Select(g => g.Name);
    }
}

4. External Configuration Switching

You can configure which implementation is bound without modifying any C# code! In appsettings.json or services.json:

{
  "Services": [
    {
      "Service": "MyApp.IPaymentGateway, MyApp",
      "Implementation": "MyApp.PayPalPaymentGateway, MyApp",
      "Lifetime": "Scoped"
    }
  ]
}

By applying external configuration (services.AddDixorJson("services.json")), your application dynamically switches the default provider across test, staging, and production environments.
