Phone & Contact Validation Overview

Dixor.Validation.Phone and Dixor.Validation.Contact provide high-performance, offline telephone number validation, formatting, country and regional circle detection, and line type classification adhering strictly to ITU-T E.164 and ISO 3166-1 standards.

Key Features

  1. Global ITU-T E.164 Dialing Standards:

    • Full offline support for 240+ international countries and territories.
    • International country calling code resolution (+1, +44, +91, +81, etc.).
    • Disambiguation for shared calling code plans (e.g. NANP +1 between US, Canada, Bahamas, Jamaica, Puerto Rico, etc.).
    • National trunk prefix handling (e.g. 0 in UK/India/Australia, 1 in NANP).

  2. Geographic State & Circle Detection:

    • Detects all 50 US states & DC from domestic area codes.
    • Detects Canadian provinces (Ontario, Quebec, British Columbia, Alberta, etc.).
    • Detects Indian telecom circles and metro areas (Delhi NCR, Mumbai, Kolkata, Chennai, Bengaluru, Pune, Hyderabad, Ahmedabad, Jaipur, etc.).
    • Detects UK cities & regions (London, Birmingham, Manchester, Edinburgh, Glasgow, etc.).
    • Detects Australian states & territories (NSW/ACT, VIC/TAS, QLD, SA/WA/NT).
    • Detects German metropolitan areas (Berlin, Munich, Hamburg, Frankfurt, Cologne, etc.).

  3. Line Type Classification:

    • Distinguishes Mobile, FixedLine, TollFree (e.g. 1800, 800), PremiumRate (900), and Emergency (911, 112, 999, 100) numbers.

  4. Multiple Standardized Formats:

    • Canonical E.164 (+12025550123).
    • International grouped representation (+1 202 555 0123).
    • Domestic national representation ((202) 555-0123 or 020 7946 0919).
    • RFC 3966 URI representation (tel:+1-202-555-0123).

  5. Extensible Contact Intelligence:

    • Built-in instant offline intelligence (ContactLookupResult).
    • Extensible IPhoneLookupProvider interface allowing users to plug in custom REST API lookups (e.g., TrueCaller, Twilio Lookup, Numverify) or internal LDAP/ActiveDirectory servers without hardcoding paid API keys into the core package.

Quick Example

using Dixor.Validation.Phone;

// Simple boolean validation
bool isValid = PhoneValidator.IsValid("+1 (202) 555-0123");

// Detailed validation result
var result = PhoneValidator.Validate("+91 98765 43210");
if (result.IsValid)
{
    // Extract breakdown
    PhoneInfo info = PhoneValidator.GetInfo("+91 98765 43210");
    Console.WriteLine($"Country: {info.Country.Name} ({info.Country.Iso2})");
    Console.WriteLine($"Calling Code: {info.CountryCallingCode}");
    Console.WriteLine($"National Number: {info.NationalNumber}");
    Console.WriteLine($"Region: {info.Region}");
    Console.WriteLine($"Line Type: {info.NumberType}");
    Console.WriteLine($"E.164: {info.FormattedE164}");
    Console.WriteLine($"National: {info.FormattedNational}");
}
