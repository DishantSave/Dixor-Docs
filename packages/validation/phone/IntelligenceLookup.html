Extensible Contact Intelligence Lookup

Dixor.Validation.Phone includes an extensible provider model for contact intelligence lookups via IPhoneLookupProvider:

public interface IPhoneLookupProvider
{
    string ProviderName { get; }
    Task<ContactLookupResult> LookupAsync(PhoneInfo phoneInfo, CancellationToken cancellationToken = default);
}

Default Offline Intelligence

By default, PhoneValidator.LookupAsync uses DefaultOfflineLookupProvider, which extracts instant zero-latency intelligence from the built-in ITU and ISO database:

  • Country name and ISO code.
  • State, province, or telecom circle.
  • Area code.
  • Phone line classification (Mobile, FixedLine, TollFree).
  • Canonical E.164 number.

Integrating Custom Third-Party Providers (TrueCaller / Twilio)

To integrate a third-party directory API (such as TrueCaller, Twilio Lookup, Numverify, or your organization's internal employee database), implement IPhoneLookupProvider and assign it in PhoneValidationOptions:

public sealed class MyCustomLookupProvider : IPhoneLookupProvider
{
    public string ProviderName => "My Enterprise Directory";

    public async Task<ContactLookupResult> LookupAsync(PhoneInfo phoneInfo, CancellationToken cancellationToken = default)
    {
        // Call your external API or database here
        var user = await CallExternalDirectoryApiAsync(phoneInfo.FormattedE164, cancellationToken);

        return new ContactLookupResult(
            rawPhone: phoneInfo.RawInput,
            formattedE164: phoneInfo.FormattedE164,
            countryName: phoneInfo.Country.Name,
            iso2: phoneInfo.Country.Iso2,
            stateOrRegion: phoneInfo.Region,
            city: user.City,
            registeredName: user.FullName,
            carrier: user.Carrier,
            numberType: phoneInfo.NumberType,
            timezone: user.Timezone,
            isFound: user != null,
            providerName: ProviderName);
    }
}

// Usage:
var options = new PhoneValidationOptions
{
    LookupProvider = new MyCustomLookupProvider()
};

var result = await PhoneValidator.LookupAsync("+1 (202) 555-0123", options);
Console.WriteLine($"Registered Name: {result.RegisteredName}");
