PhoneInfo

The PhoneInfo class represents the parsed breakdown of a valid telephone number.

Properties

Property Type Description
RawInput string The original input string provided to the validator.
Digits string The clean digits-only representation including calling code digits.
CountryCallingCode string The international calling code with + (e.g. "+1", "+91").
NationalNumber string The national subscriber number excluding calling code and trunk prefix.
AreaCode string? The domestic area code or national destination code, if identifiable.
Country CountryInfo Metadata for the identified country (Name, Iso2, Iso3, CallingCode, TrunkPrefix, Lengths).
Region string? Identified state, province, circle, or major city (e.g. "New York", "Mumbai").
NumberType PhoneNumberType Line classification (Mobile, FixedLine, TollFree, PremiumRate, Emergency).
IsValid bool Indicates whether the phone number is valid.
FormattedE164 string Standardized canonical format (e.g. +12025550123).
FormattedInternational string Grouped international representation (e.g. +1 202 555 0123).
FormattedNational string Domestic representation with trunk prefix (e.g. (202) 555-0123).
FormattedRfc3966 string RFC 3966 URI representation (e.g. tel:+1-202-555-0123).
