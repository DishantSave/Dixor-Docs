PhoneValidationError

The PhoneValidationError enum defines strongly typed error codes returned when phone number validation fails.

Error Codes

Member Value Description
None 0 Validation succeeded without error.
Null 1 The provided phone number string is null.
Empty 2 The provided phone number string is empty.
WhiteSpace 3 The provided phone number string contains only whitespace.
InvalidCharacters 4 The phone number contains invalid characters (letters or disallowed symbols).
InvalidFormat 5 The structural format is invalid.
MissingCountryCode 6 No country code was detected and no fallback DefaultCountryIso was provided.
InvalidCountryCode 7 The country calling code is not recognized in the ITU-T registry.
CountryNotAllowed 8 The identified country is disallowed by options whitelist/blacklist.
NumberTooShort 9 Total digits are below the ITU minimum (3 digits) or country minimum.
NumberTooLong 10 Total digits exceed the ITU maximum (15 digits) or country maximum.
InvalidLengthForCountry 11 The national number length is invalid for the resolved country.
InvalidAreaCode 12 The area code is invalid for the country.
InvalidNationalNumber 13 The national number contains invalid digits.
InvalidTrunkPrefix 14 The national trunk prefix is invalid or misplaced.
