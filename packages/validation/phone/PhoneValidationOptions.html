PhoneValidationOptions

The PhoneValidationOptions class allows customizing parsing, fallback countries, and character constraints.

Properties

Property Type Default Description
DefaultCountryIso string? null Fallback ISO alpha-2 country code (e.g. "US", "IN") used when input omits the + calling code.
RequireCountryCode bool false When true, numbers without explicit + calling codes are rejected with MissingCountryCode.
AllowSpecialCharacters bool true When true, standard delimiters (-, ., spaces, ()) are accepted in the input.
StrictLength bool true When true, enforces strict national number length constraints for the identified country.
AllowedCountryIsos HashSet<string>? null Whitelist of permitted ISO-2 codes. Numbers from other countries fail with CountryNotAllowed.
BlockedCountryIsos HashSet<string>? null Blacklist of disallowed ISO-2 codes. Numbers from these countries fail with CountryNotAllowed.
LookupProvider IPhoneLookupProvider? null Custom contact intelligence provider (e.g., TrueCaller, Twilio, enterprise directory).

Usage Example

using Dixor.Validation.Phone;

var options = new PhoneValidationOptions
{
    DefaultCountryIso = "US",
    RequireCountryCode = false,
    AllowSpecialCharacters = true,
    AllowedCountryIsos = new HashSet<string>(StringComparer.OrdinalIgnoreCase) { "US", "CA" }
};

// Valid domestic number parsed as US
bool isValid = PhoneValidator.IsValid("(202) 555-0123", options);
