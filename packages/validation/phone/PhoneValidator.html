PhoneValidator API

PhoneValidator is the primary static entry point for phone number validation, parsing, formatting, and intelligence in Dixor.Validation.Phone.

Static Methods

Validation

public static bool IsValid(string? phone, PhoneValidationOptions? options = null)
public static ValidationResult<PhoneValidationError> Validate(string? phone, PhoneValidationOptions? options = null)
  • IsValid: Returns true if the input phone number is valid according to E.164 and country rules; otherwise false.
  • Validate: Returns a ValidationResult<PhoneValidationError> containing the exact reason for failure if invalid.
