Address & Geographic Validation Overview

Dixor.Validation.Address provides high-performance, offline validation and intelligence for international postal addresses, ISO 3166-1 country codes, ISO 3166-2 state/province subdivisions, and national postal/ZIP/PIN codes.

Key Features

  • ISO 3166-1 Country Code Validation: Validates two-letter (alpha-2), three-letter (alpha-3), three-digit numeric-3 codes, and common English country names across 240+ countries and territories.
  • ISO 3166-2 State & Subdivision Validation: Complete catalog of states, provinces, and union territories for major countries (India: all 28 states + 8 UTs, United States: all 50 states + DC + territories, Canada: 10 provinces + 3 territories, Australia, United Kingdom, Germany).
  • Cross-Field Consistency Enforcement: Automatically detects and rejects mismatched combinations (e.g., specifying California with India, or an Indian 6-digit PIN code with the United States).
  • Postal & PIN Code Validation: Enforces national postal syntax rules for 100+ countries (India 6-digit PIN code, US 5-digit ZIP / ZIP+4, UK alphanumeric, Canada alternating A1A 1A1, etc.).
  • Composite Address Verification: Validates full postal address structures with standardized single-line formatting and equality comparison.
  • Zero Third-Party Dependencies: Self-contained in-memory database with microsecond validation speeds.

Quick Start

1. Country Code Validation

using Dixor.Validation.Address;

// Validate by ISO-2, ISO-3, Numeric-3, or Country Name
bool validIso2 = AddressValidator.IsValidCountryCode("IN");        // true
bool validIso3 = AddressValidator.IsValidCountryCode("IND");       // true
bool validNum  = AddressValidator.IsValidCountryCode("356");       // true
bool validName = AddressValidator.IsValidCountryCode("India");     // true

// Inspect country metadata
if (AddressValidator.TryGetCountry("IND", out CountryCodeInfo? country))
{
    Console.WriteLine($"Country: {country.Name} ({country.Iso2} / {country.Iso3})");
    Console.WriteLine($"Numeric: {country.NumericCode}");
    Console.WriteLine($"Official: {country.OfficialName}");
}

// Normalize country code
string iso2 = AddressValidator.NormalizeCountryCode("india"); // "IN"

2. State & Subdivision Code Validation

// Validate state code within country context
bool validState = AddressValidator.IsValidStateCode("MH", "IN");         // true (Maharashtra)
bool validFull  = AddressValidator.IsValidStateCode("IN-MH", "IN");      // true
bool validUS    = AddressValidator.IsValidStateCode("CA", "US");         // true (California)

// Detect cross-country mismatches!
var mismatch = AddressValidator.ValidateStateCode("CA", "IN"); // California with India!
Console.WriteLine(mismatch.Error); // StateCountryMismatch

// Retrieve subdivision details
StateCodeInfo state = AddressValidator.GetState("MH", "IN");
Console.WriteLine($"Name: {state.Name}, Category: {state.Category}, Full ISO: {state.IsoSubdivisionCode}");

3. Postal Code Validation

// Validate Indian 6-digit PIN code
bool validPin = AddressValidator.IsValidPostalCode("400001", "IN"); // true
bool invalidPin = AddressValidator.IsValidPostalCode("012345", "IN"); // false (cannot start with 0)

// Validate US ZIP code or ZIP+4
bool validZip = AddressValidator.IsValidPostalCode("90210", "US"); // true
bool validZip4 = AddressValidator.IsValidPostalCode("12345-6789", "US"); // true

4. Composite Address Validation

AddressData address = new()
{
    Street = "123 Mahatma Gandhi Road",
    City = "Mumbai",
    StateCode = "MH",
    PostalCode = "400001",
    CountryCode = "IN"
};

var result = AddressValidator.Validate(address);

if (result.IsValid)
{
    AddressInfo info = AddressValidator.GetInfo(address);
    Console.WriteLine(info.FormattedSingleLine);
    // Output: 123 Mahatma Gandhi Road, Mumbai, MH 400001, India
}
