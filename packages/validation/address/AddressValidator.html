AddressValidator

The AddressValidator static class is the primary entry point for address, country code, state code, and postal code validation in Dixor.Validation.

Namespace

using Dixor.Validation.Address;

Country Code Endpoints

Method Return Type Description
IsValidCountryCode(code, options) bool Returns true if the input is a valid ISO 3166-1 alpha-2, alpha-3, numeric-3, or common country name.
ValidateCountryCode(code, options) ValidationResult<AddressValidationError> Validates the country code with detailed error reporting.
TryGetCountry(codeOrName, out info, options) bool Resolves structured CountryCodeInfo.
GetCountry(codeOrName, options) CountryCodeInfo Resolves CountryCodeInfo, throwing FormatException if invalid.
NormalizeCountryCode(code) string Converts country code to standard uppercase ISO 3166-1 alpha-2 format.
GetAllCountries() IReadOnlyList<CountryCodeInfo> Returns all cataloged ISO 3166-1 countries.

Method Return Type Description

GetAllStates() IReadOnlyList<StateCodeInfo> Returns all registered subdivisions across all countries.
