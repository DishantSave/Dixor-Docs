Country Code Validation (ISO 3166-1)

The country code validation engine in Dixor.Validation.Address provides compliance checking against the international ISO 3166-1 standard. It accepts and cross-references two-letter alpha codes, three-letter alpha codes, three-digit numeric codes, and standard English country names.

Supported Code Formats

Format Standard Description Example
Alpha-2 ISO 3166-1 alpha-2 Two-letter country code "IN", "US", "GB", "CA"
Alpha-3 ISO 3166-1 alpha-3 Three-letter country code "IND", "USA", "GBR", "CAN"
Numeric-3 ISO 3166-1 numeric Three-digit numeric code "356", "840", "826", "124"
Country Name ISO 3166 Common Name Case-insensitive English name "India", "United States", "United Kingdom"

API Reference

AddressValidator.IsValidCountryCode

Determines whether the specified string represents a valid recognized country identifier.

using Dixor.Validation.Address;

bool isIndiaAlpha2 = AddressValidator.IsValidCountryCode("IN");    // true
bool isIndiaAlpha3 = AddressValidator.IsValidCountryCode("IND");   // true
bool isIndiaNum    = AddressValidator.IsValidCountryCode("356");   // true
bool isIndiaName   = AddressValidator.IsValidCountryCode("India"); // true
bool isInvalid     = AddressValidator.IsValidCountryCode("ZZ");    // false

AddressValidator.ValidateCountryCode

Returns a ValidationResult<AddressValidationError> detailing the outcome.

var result = AddressValidator.ValidateCountryCode("ZZ");

if (!result.IsValid)
{
    Console.WriteLine(result.Error); // InvalidCountryCode
}

AddressValidator.TryGetCountry & GetCountry

Resolves comprehensive metadata including ISO codes, official titles, and postal system capabilities.

if (AddressValidator.TryGetCountry("IND", out CountryCodeInfo? info))
{
    Console.WriteLine($"ISO-2: {info.Iso2}");             // IN
    Console.WriteLine($"ISO-3: {info.Iso3}");             // IND
    Console.WriteLine($"Numeric: {info.NumericCode}");     // 356
    Console.WriteLine($"Name: {info.Name}");               // India
    Console.WriteLine($"Official: {info.OfficialName}");   // Republic of India
    Console.WriteLine($"Subdivisions: {info.HasSubdivisions}"); // true
    Console.WriteLine($"Postal Codes: {info.HasPostalCodes}"); // true
}

AddressValidator.NormalizeCountryCode

Converts any valid identifier (alpha-3, numeric-3, or common name) into standard uppercase ISO 3166-1 alpha-2 format.

string norm1 = AddressValidator.NormalizeCountryCode("IND");            // "IN"
string norm2 = AddressValidator.NormalizeCountryCode("356");            // "IN"
string norm3 = AddressValidator.NormalizeCountryCode("india");          // "IN"
string norm4 = AddressValidator.NormalizeCountryCode("United States");  // "US"

Whitelisting & Blacklisting Countries

You can restrict allowed countries for business compliance using AddressValidationOptions:

var options = new AddressValidationOptions
{
    AllowedCountryIsos = new HashSet<string>(StringComparer.OrdinalIgnoreCase) { "IN", "US", "CA", "GB" },
    BlockedCountryIsos = new HashSet<string>(StringComparer.OrdinalIgnoreCase) { "RU" }
};

// Valid because IN is in the whitelist
bool validIN = AddressValidator.IsValidCountryCode("IN", options); // true

// Rejected because DE is not in the whitelist
var result = AddressValidator.ValidateCountryCode("DE", options);
Console.WriteLine(result.Error); // CountryNotAllowed
