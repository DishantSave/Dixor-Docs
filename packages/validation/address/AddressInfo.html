Address Information Models

Dixor.Validation.Address provides strongly typed, immutable metadata models for validated addresses and individual components.

AddressInfo

Encapsulates complete structured intelligence for a verified composite address:

Property Type Description
RawData AddressData The original input address data.
Country CountryCodeInfo? Resolved ISO 3166-1 country metadata.
State StateCodeInfo? Resolved ISO 3166-2 state or subdivision metadata.
PostalCode PostalCodeInfo? Resolved postal code metadata.
City string Normalized city or municipality name.
FormattedStreet string Normalized street address line(s).
FormattedSingleLine string Standardized single-line formatted address string.
IsValid bool true if the address satisfies all validation constraints.

CountryCodeInfo

Property Type Description
Iso2 string Two-letter ISO 3166-1 alpha-2 code (e.g. "IN").
Iso3 string Three-letter ISO 3166-1 alpha-3 code (e.g. "IND").
NumericCode string Three-digit ISO 3166-1 numeric-3 code (e.g. "356").
Name string Common English country name (e.g. "India").
OfficialName string Official diplomatic title (e.g. "Republic of India").
HasSubdivisions bool true if ISO 3166-2 states are registered.
HasPostalCodes bool true if postal codes are used in this country.

StateCodeInfo

Property Type Description
CountryIso2 string Parent country two-letter code (e.g. "IN").
Code string Primary short state code (e.g. "MH").
IsoSubdivisionCode string Full ISO 3166-2 code (e.g. "IN-MH").
Name string Common English state name (e.g. "Maharashtra").
Category string Administrative category (e.g. "State", "Union Territory", "Province").

PostalCodeInfo

Property Type Description
CountryIso2 string Parent country code.
RawInput string Raw input string.
NormalizedPostalCode string Normalized uppercase postal code.
FormatRegexPattern string Enforced regular expression pattern.
SampleFormat string Sample valid format.
Description string Pattern description.
IsValid bool Validation status.
