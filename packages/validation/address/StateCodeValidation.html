State & Subdivision Code Validation (ISO 3166-2)

The state and province validation engine in Dixor.Validation.Address implements the international ISO 3166-2 standard for national administrative subdivisions. It validates short administrative abbreviations, full ISO 3166-2 subdivision codes, and full state/province names while enforcing cross-country relationship constraints.

Core Capabilities

  1. Short State Codes: Validates domestic state codes (e.g., "MH", "CA", "ON", "NSW").
  2. Full ISO 3166-2 Codes: Validates combined prefix codes (e.g., "IN-MH", "US-CA", "CA-ON", "AU-NSW").
  3. Full State Names: Recognizes common English names (e.g., "Maharashtra", "California", "Ontario").
  4. Cross-Country Verification: Guarantees that a state strictly belongs to the specified country, preventing invalid pairings such as California with India.

API Reference

AddressValidator.IsValidStateCode

Determines whether a state code or name is valid for an optional country.

using Dixor.Validation.Address;

// India states
bool isMH = AddressValidator.IsValidStateCode("MH", "IN");          // true
bool isFullIN = AddressValidator.IsValidStateCode("IN-MH", "IN");   // true
bool isNameIN = AddressValidator.IsValidStateCode("Maharashtra", "IN"); // true

// United States states
bool isCA = AddressValidator.IsValidStateCode("CA", "US");          // true
bool isFullUS = AddressValidator.IsValidStateCode("US-CA", "US");   // true
bool isNameUS = AddressValidator.IsValidStateCode("California", "US"); // true

Detecting Cross-Country Mismatches

When EnforceStateBelongsToCountry is enabled (the default), AddressValidator verifies that the state actually belongs to the given country:

// California does NOT belong to India!
var result = AddressValidator.ValidateStateCode("CA", "IN");

if (!result.IsValid)
{
    Console.WriteLine(result.Error);
    // Output: StateCountryMismatch
}

AddressValidator.TryGetState & GetState

Retrieves structured StateCodeInfo containing the parent country, short code, ISO-2 subdivision code, full name, and administrative category.

if (AddressValidator.TryGetState("MH", "IN", out StateCodeInfo? info))
{
    Console.WriteLine($"Code: {info.Code}");                       // MH
    Console.WriteLine($"Full ISO-2: {info.IsoSubdivisionCode}");   // IN-MH
    Console.WriteLine($"Name: {info.Name}");                       // Maharashtra
    Console.WriteLine($"Category: {info.Category}");               // State
    Console.WriteLine($"Country: {info.CountryIso2}");             // IN
}

AddressValidator.GetStatesForCountry

Returns a list of all registered states and territories for a country:

var indiaSubdivisions = AddressValidator.GetStatesForCountry("IN");
Console.WriteLine($"Total Indian States & UTs: {indiaSubdivisions.Count}"); // 36

var usSubdivisions = AddressValidator.GetStatesForCountry("US");
Console.WriteLine($"Total US States & Territories: {usSubdivisions.Count}"); // 56
