Postal & ZIP Code Validation

Dixor.Validation.Address includes built-in national postal format rules for over 100 countries, validating domestic digit sequences, alphanumeric patterns, visual delimiters, and special regional exceptions.

National Postal Formats

Country Code Format Regex Sample Format Description
India IN ^[1-9][0-9]{5}$ 400001 6 digits (first digit 1–9)
United States US ^\d{5}(-\d{4})?$ 90210 / 12345-6789 5 digits or ZIP+4
United Kingdom GB ^[A-Z]{1,2}[0-9][A-Z0-9]? ?[0-9][A-Z]{2}$ SW1A 1AA Alphanumeric UK postcode
Canada CA ^[A-CEGHJ-NPR-TVXY][0-9][A-CEGHJ-NPR-TV-Z] ?[0-9][A-CEGHJ-NPR-TV-Z][0-9]$ K1A 0B1 Alternating alphanumeric (A1A 1A1)
Australia AU ^[0-9]{4}$ 2000 4 digits
Germany DE ^[0-9]{5}$ 10115 5 digits
France FR ^[0-9]{5}$ 75001 5 digits
Japan JP ^[0-9]{3}-?[0-9]{4}$ 100-0001 7 digits with optional hyphen
Singapore SG ^[0-9]{6}$ 018956 6 digits
Brazil BR ^[0-9]{5}-?[0-9]{3}$ 01310-100 8 digits (12345-678)

API Reference

AddressValidator.IsValidPostalCode

Determines whether the specified postal code satisfies the country's national format.

using Dixor.Validation.Address;

// India 6-digit PIN code
bool isMumbaiPin = AddressValidator.IsValidPostalCode("400001", "IN"); // true
bool isInvalidPin = AddressValidator.IsValidPostalCode("012345", "IN"); // false (starts with 0)

// US ZIP code
bool isBeverlyHills = AddressValidator.IsValidPostalCode("90210", "US"); // true
bool isZipPlus4 = AddressValidator.IsValidPostalCode("12345-6789", "US"); // true

AddressValidator.TryGetPostalCodeInfo

Retrieves structured postal metadata:

if (AddressValidator.TryGetPostalCodeInfo("400001", "IN", out PostalCodeInfo? info))
{
    Console.WriteLine($"Normalized: {info.NormalizedPostalCode}"); // 400001
    Console.WriteLine($"Pattern: {info.FormatRegexPattern}");      // ^[1-9][0-9]{5}$
    Console.WriteLine($"Description: {info.Description}");          // 6 digits (first digit 1-9)
    Console.WriteLine($"Sample: {info.SampleFormat}");              // 400001
}

Countries Without Postal Code Systems

Certain nations (such as the United Arab Emirates AE and Qatar QA) do not use domestic postal codes. AddressValidator recognizes this and handles it cleanly:

// Empty postal code for UAE is valid
bool validUaeEmpty = AddressValidator.IsValidPostalCode(string.Empty, "AE"); // true

// Entering an unneeded postal code for UAE triggers PostalCodeCountryMismatch
var errorUae = AddressValidator.ValidatePostalCode("12345", "AE");
Console.WriteLine(errorUae.Error); // PostalCodeCountryMismatch
