AadhaarValidationError

The AadhaarValidationError enum defines distinct failure reasons when an Indian Aadhaar card number fails validation.

namespace Dixor.Validation.Aadhaar;

public enum AadhaarValidationError

Enumeration Members

Value Name Description
0 None The Aadhaar number is valid and satisfies all format and Verhoeff checksum constraints.
1 Null The input string is null.
2 Empty The input string is empty ("").
3 WhiteSpace The input string consists exclusively of whitespace characters.
4 InvalidCharacters The input contains invalid non-numeric characters (characters other than permitted spaces or hyphens).
5 InvalidLength The normalized string length is not exactly 12 numeric digits.
6 InvalidStartingDigit The Aadhaar number begins with 0 or 1. UIDAI specifications mandate starting digits 2 through 9.
7 RepeatedDigits The Aadhaar number consists of identical repeated digits (e.g., 2222 2222 2222).
8 InvalidChecksum The Aadhaar number failed the Verhoeff algorithm dihedral group \(D_5\) checksum verification.

Diagnostic Handling Example

var result = AadhaarValidator.Validate(userInput);

switch (result.Error)
{
    case AadhaarValidationError.None:
        Console.WriteLine("Aadhaar number is valid.");
        break;

    case AadhaarValidationError.InvalidStartingDigit:
        Console.WriteLine("Invalid Aadhaar: Numbers cannot begin with 0 or 1.");
        break;

    case AadhaarValidationError.InvalidChecksum:
        Console.WriteLine("Invalid Aadhaar: Verhoeff check digit mismatch.");
        break;

    case AadhaarValidationError.RepeatedDigits:
        Console.WriteLine("Invalid Aadhaar: Repeating placeholder numbers are rejected.");
        break;

    default:
        Console.WriteLine($"Aadhaar validation failed with error: {result.Error}");
        break;
}
