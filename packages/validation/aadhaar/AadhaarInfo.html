AadhaarInfo

The AadhaarInfo class encapsulates parsed metadata, formatted string representations, privacy-masked tokens, and checksum attributes for an Indian Aadhaar card number.

namespace Dixor.Validation.Aadhaar;

public sealed class AadhaarInfo

Properties

Property Type Description
RawInput string The original raw input string provided to the validator.
Digits string The clean 12-digit unformatted number (e.g., "367598346015").
Formatted string The standard 4-digit grouped representation with space separators (e.g., "3675 9834 6015").
Masked string The privacy-compliant masked representation redacting the first 8 digits (e.g., "XXXX XXXX 6015").
LastFourDigits string The last 4 digits of the Aadhaar number (e.g., "6015").
CheckDigit int The Verhoeff algorithm check digit (the 12th digit).
IsValid bool Indicates whether the Aadhaar number satisfies all validation constraints.

Usage Example

if (AadhaarValidator.TryGetInfo("3675-9834-6015", out AadhaarInfo? info))
{
    Console.WriteLine($"Raw Input:      {info.RawInput}");
    Console.WriteLine($"Clean Digits:   {info.Digits}");
    Console.WriteLine($"Formatted:      {info.Formatted}");
    Console.WriteLine($"Masked:         {info.Masked}");
    Console.WriteLine($"Last 4 Digits:  {info.LastFourDigits}");
    Console.WriteLine($"Check Digit:    {info.CheckDigit}");
    Console.WriteLine($"Is Valid:       {info.IsValid}");
}
