AadhaarValidationOptions

The AadhaarValidationOptions class configures validation strictness, formatting rules, and repetition constraints for Aadhaar card numbers.

namespace Dixor.Validation.Aadhaar;

public sealed class AadhaarValidationOptions

Properties

Property Type Default Description
AllowSpecialCharacters bool true Allows spaces ( ) and hyphens (-) as grouping delimiters in the input string.
EnforceStartingDigitRule bool true Mandates that the first digit cannot be 0 or 1 per UIDAI guidelines.
DisallowRepeatedDigits bool true Rejects dummy or placeholder numbers where all 12 digits are identical (e.g., 2222 2222 2222).

Static Instances

AadhaarValidationOptions.Default

Provides a cached, thread-safe default instance with all standard options enabled:

public static AadhaarValidationOptions Default { get; }

Examples

Strict Mode (No Spaces Allowed)

var options = new AadhaarValidationOptions
{
    AllowSpecialCharacters = false // Requires exact continuous 12 digits
};

bool isValidWithSpace = AadhaarValidator.IsValid("3675 9834 6015", options); // false
bool isValidClean     = AadhaarValidator.IsValid("367598346015", options);   // true

Relaxed Testing Mode

var options = new AadhaarValidationOptions
{
    DisallowRepeatedDigits = false // Allows test numbers like 2222 2222 2222
};
