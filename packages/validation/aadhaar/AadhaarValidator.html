AadhaarValidator API Reference

The AadhaarValidator class (and its alias AdhaarValidator) provides static methods for validating, formatting, masking, parsing, and generating Indian UIDAI Aadhaar numbers.

namespace Dixor.Validation.Aadhaar;

public static class AadhaarValidator
public static class AdhaarValidator // Alias

Methods

IsValid

Determines whether the specified string represents a valid 12-digit Aadhaar card number.

public static bool IsValid(string? aadhaar, AadhaarValidationOptions? options = null);

Parameters

  • aadhaar (string?): The raw or formatted Aadhaar number.
  • options (AadhaarValidationOptions?): Optional validation options. Defaults to AadhaarValidationOptions.Default.

Returns

bool: true if the input is non-null, valid length, valid starting digit, non-repetitive, and passes the Verhoeff checksum; otherwise, false.

Example

bool valid = AadhaarValidator.IsValid("3675 9834 6015"); // true
bool invalid = AadhaarValidator.IsValid("0123 4567 8901"); // false

Validate

Validates an Aadhaar number and returns a structured ValidationResult<AadhaarValidationError> containing error diagnostics if invalid.

public static ValidationResult<AadhaarValidationError> Validate(
    string? aadhaar,
    AadhaarValidationOptions? options = null);

Example

var result = AadhaarValidator.Validate("2222 2222 2222");

if (!result.IsValid)
{
    Console.WriteLine($"Error: {result.Error}"); // RepeatedDigits
}

TryGetInfo

Attempts to parse the specified string into a structured AadhaarInfo record.

public static bool TryGetInfo(
    string? aadhaar,
    out AadhaarInfo? info,
    AadhaarValidationOptions? options = null);

Returns

bool: true if valid and successfully parsed; otherwise, false with info set to null.

Example

if (AadhaarValidator.TryGetInfo("3675 9834 6015", out var info))
{
    Console.WriteLine($"Masked: {info.Masked}");
}

GetInfo

Retrieves structured metadata, throwing a FormatException if the number is invalid.

public static AadhaarInfo GetInfo(
    string aadhaar,
    AadhaarValidationOptions? options = null);

Exceptions

  • ArgumentNullException: When aadhaar is null.
  • FormatException: When aadhaar fails format or checksum validation.

Normalize and TryNormalize

Strips all whitespace, dashes, and delimiters to return the raw 12 digits.

public static string Normalize(string aadhaar);
public static bool TryNormalize(string? aadhaar, out string? normalized);

Example

string clean = AadhaarValidator.Normalize("3675 - 9834 - 6015"); // "367598346015"

Format

Formats the 12 numeric digits into standard 4-digit groups (1234 5678 9012).

public static string Format(string aadhaar);

Mask

Redacts the first 8 digits for RBI and UIDAI data privacy compliance.

public static string Mask(
    string aadhaar,
    char maskChar = 'X',
    bool includeSpaces = true);

Parameters

  • aadhaar (string): The raw or formatted Aadhaar number.
  • maskChar (char): Character to replace the first 8 digits (defaults to 'X').
  • includeSpaces (bool): Whether to include group spacing (defaults to true).

Example

string masked1 = AadhaarValidator.Mask("367598346015"); // "XXXX XXXX 6015"
string masked2 = AadhaarValidator.Mask("367598346015", '*', false); // "********6015"

AreEqual

Compares two Aadhaar representations for semantic equality after normalization.

public static bool AreEqual(string? first, string? second);

Example

bool match = AadhaarValidator.AreEqual("3675 9834 6015", "3675-9834-6015"); // true

CalculateCheckDigit and Generate

Computes the Verhoeff check digit or generates a complete valid Aadhaar number.

public static int CalculateCheckDigit(string elevenDigits);
public static string Generate(string elevenDigitsPrefix);

Example

int check = AadhaarValidator.CalculateCheckDigit("78291045638"); // 4
string aadhaar = AadhaarValidator.Generate("78291045638");       // "782910456384"
