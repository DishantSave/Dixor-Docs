Aadhaar Card Validation Overview

Dixor.Validation.Aadhaar provides robust, high-performance offline validation, checksum calculation, normalization, and data privacy masking for Indian Aadhaar numbers issued by the Unique Identification Authority of India (UIDAI).

What is Aadhaar?

Aadhaar is a 12-digit random identification number issued to residents of India by UIDAI. It is the world's largest biometric identity system.

Key technical specifications of an Aadhaar number:

  • Format: Exactly 12 numeric digits (dddd dddd dddd).
  • Starting Digit: The first digit cannot be 0 or 1. Valid Aadhaar numbers start with digits 2 through 9.
  • Verhoeff Checksum: The 12th digit is an error-detecting check digit computed using the Verhoeff algorithm based on the non-commutative dihedral group \(D_5\).
  • No Personal Data Encoded: The number contains no demographic, regional, or personal classification indicators.
  • Privacy Masking: Regulatory mandates (UIDAI, RBI, IRDAI) require redacting the first 8 digits in documents and databases (e.g., XXXX XXXX 1234).

Key Features

  • Verhoeff Cryptographic Checksum: Verifies the 12th digit using the dihedral group \(D_5\) permutation and multiplication tables. Detects 100% of single-digit errors and 100% of adjacent transposition errors.
  • Starting Digit Validation: Enforces UIDAI guidelines disallowing starting digits 0 and 1.
  • Repetitive Digits Guard: Detects and rejects dummy/test inputs with repeated digits (e.g., 2222 2222 2222).
  • Flexible Delimiters: Seamlessly parses clean digits, space-grouped (1234 5678 9012), or hyphenated (1234-5678-9012) strings.
  • RBI/UIDAI Privacy Masking: Standard masking utility converting 1234 5678 9012 into XXXX XXXX 9012 with configurable masking characters.
  • Check Digit Calculator & Generator: Compute the exact Verhoeff digit for an 11-digit prefix or generate complete valid Aadhaar numbers for testing.
  • Spelling Convenience: Exposes both AadhaarValidator and AdhaarValidator static facades.

Quick Start

1. Basic Validity Check

using Dixor.Validation.Aadhaar;

// Validate directly
bool isValid = AadhaarValidator.IsValid("3675 9834 6015"); // true
bool isInvalid = AadhaarValidator.IsValid("0123 4567 8901"); // false (starts with 0)

// Spelling alias 'AdhaarValidator'
bool validAlias = AdhaarValidator.IsValid("3675 9834 6015"); // true

2. Comprehensive Validation with Error Codes

var result = AadhaarValidator.Validate("1234 5678 9012");

if (!result.IsValid)
{
    Console.WriteLine($"Failure Reason: {result.Error}");
    // Outputs: InvalidStartingDigit
}

3. Normalization and Privacy Masking

string raw = "  3675 - 9834 - 6015 ";

// Strip delimiters
string clean = AadhaarValidator.Normalize(raw); // "367598346015"

// Standard 4-digit grouping
string formatted = AadhaarValidator.Format(clean); // "3675 9834 6015"

// UIDAI/RBI privacy masking
string masked = AadhaarValidator.Mask(clean); // "XXXX XXXX 6015"

// Custom mask character and continuous format
string custom = AadhaarValidator.Mask(clean, maskChar: '*', includeSpaces: false); // "********6015"

4. Structured Identity Metadata

if (AadhaarValidator.TryGetInfo("3675 9834 6015", out AadhaarInfo? info))
{
    Console.WriteLine($"Clean:       {info.Digits}");         // "367598346015"
    Console.WriteLine($"Formatted:   {info.Formatted}");      // "3675 9834 6015"
    Console.WriteLine($"Masked:      {info.Masked}");         // "XXXX XXXX 6015"
    Console.WriteLine($"Last 4:      {info.LastFourDigits}"); // "6015"
    Console.WriteLine($"Check Digit: {info.CheckDigit}");     // 5
}

5. Check Digit Calculation & Generator

// Calculate Verhoeff check digit for an 11-digit prefix
int checkDigit = AadhaarValidator.CalculateCheckDigit("78291045638");

// Generate complete 12-digit valid Aadhaar number
string fullAadhaar = AadhaarValidator.Generate("78291045638");
