CreditCardValidator API Reference

The CreditCardValidator class provides static methods for validating, formatting, masking, parsing, and generating international credit and debit card numbers.

namespace Dixor.Validation.CreditCard;

public static class CreditCardValidator

Methods

IsValid

Determines whether the specified card number (and optional expiry date/CVV) is valid.

public static bool IsValid(
    string? cardNumber, 
    CreditCardValidationOptions? options = null);

public static bool IsValid(
    string? cardNumber, 
    int expiryMonth, 
    int expiryYear, 
    string? cvv = null, 
    CreditCardValidationOptions? options = null);

Example

bool validCard = CreditCardValidator.IsValid("4532 0151 1283 0366"); // true
bool validWithExpiry = CreditCardValidator.IsValid("4532015112830366", 12, 2028, "123"); // true

Validate

Validates the card number and returns a structured ValidationResult<CreditCardValidationError>.

public static ValidationResult<CreditCardValidationError> Validate(
    string? cardNumber, 
    CreditCardValidationOptions? options = null);

public static ValidationResult<CreditCardValidationError> Validate(
    string? cardNumber, 
    int expiryMonth, 
    int expiryYear, 
    string? cvv = null, 
    CreditCardValidationOptions? options = null);

Example

var result = CreditCardValidator.Validate("4532015112830366", 1, 2020);
if (!result.IsValid)
{
    Console.WriteLine($"Error: {result.Error}"); // Expired
}

TryGetInfo and GetInfo

Extracts structured CreditCardInfo metadata including network classification, BIN, formatted representation, masked string, and check digit.

public static bool TryGetInfo(
    string? cardNumber, 
    out CreditCardInfo? info, 
    CreditCardValidationOptions? options = null);

public static CreditCardInfo GetInfo(
    string cardNumber, 
    CreditCardValidationOptions? options = null);

DetectNetwork

Identifies the card network from the leading IIN/BIN digits.

public static CardNetwork DetectNetwork(string? cardNumber);

Returns

The detected CardNetwork enum value (e.g. CardNetwork.Visa, CardNetwork.AmericanExpress, CardNetwork.RuPay).

Normalize and TryNormalize

Strips spaces, hyphens, and delimiters to return raw numeric digits.

public static string Normalize(string cardNumber);
public static bool TryNormalize(string? cardNumber, out string? normalized);

Format

Formats the card number according to its network conventions (e.g., 4-4-4-4 for Visa/Mastercard, 4-6-5 for American Express, 4-6-4 for Diners Club).

public static string Format(string cardNumber);

Mask

Masks all but the last 4 digits for PCI-DSS compliance.

public static string Mask(
    string cardNumber, 
    char maskChar = '•', 
    bool includeSpaces = true);

Example

string masked1 = CreditCardValidator.Mask("4532015112830366"); // "•••• •••• •••• 0366"
string masked2 = CreditCardValidator.Mask("4532015112830366", 'X', false); // "XXXXXXXXXXXX0366"

CalculateCheckDigit and Generate

Computes the Luhn check digit or generates a complete valid card number from a prefix.

public static int CalculateCheckDigit(string prefixDigits);
public static string Generate(string prefixDigits);

Example

int check = CreditCardValidator.CalculateCheckDigit("453201511283036"); // 6
string card = CreditCardValidator.Generate("453201511283036");       // "4532015112830366"
