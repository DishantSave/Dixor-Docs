Credit & Debit Card Validation Overview

Dixor.Validation.CreditCard provides high-performance, offline validation, checksum verification, network classification, formatting, and PCI-DSS data privacy masking for international payment cards.

Key Features

  • Luhn Algorithm Checksum: Accelerated Mod-10 checksum validation with lookup-table doubling.
  • IIN / BIN Network Identification: Automatically classifies cards into 10 major global payment networks:
    • Visa (4)
    • Mastercard (51-55 & 2221-2720)
    • American Express (34, 37)
    • RuPay (60, 65, 81, 82, 508, 353, 356)
    • Discover (6011, 622126-622925, 644-649, 65)
    • JCB (3528-3589)
    • Diners Club (300-305, 36, 38, 39)
    • Maestro (50, 56-58, 6xxx)
    • China UnionPay (62)
    • Mir (2200-2204)
  • Network-Specific Valid Lengths: Validates that the digit length matches the recognized rules for the detected card brand (e.g. 15 digits for Amex, 14 digits for Diners Club, 16 for Visa/Mastercard/RuPay).
  • Expiration Date & CVV Validation: Evaluates month/year expiration boundaries and network-specific CVV length rules (3 digits for most networks, 4 digits for American Express).
  • PCI-DSS Compliant Masking: Redacts all digits except the final four (e.g., •••• •••• •••• 0366).
  • Luhn Check Digit Generator: Computes the missing check digit for any card prefix or generates valid numbers for automated test suites.

Quick Start

1. Basic Validity Check

using Dixor.Validation.CreditCard;

// Validate by card number (accepts clean digits, spaces, or hyphens)
bool isValid = CreditCardValidator.IsValid("4532 0151 1283 0366"); // true
bool isInvalid = CreditCardValidator.IsValid("4532 0151 1283 0369"); // false (tampered Luhn check digit)

2. Comprehensive Validation with Expiry & CVV

// Validate card number + expiration month/year + CVV
var result = CreditCardValidator.Validate(
    cardNumber: "3782 822463 10005",
    expiryMonth: 12,
    expiryYear: 2028,
    cvv: "1234"); // 4-digit CVV for Amex

if (!result.IsValid)
{
    Console.WriteLine($"Card rejected: {result.Error}");
}

3. Network Detection & Metadata Extraction

if (CreditCardValidator.TryGetInfo("5500 0000 0000 0004", out CreditCardInfo? info))
{
    Console.WriteLine($"Network:     {info.NetworkName}");    // "Mastercard"
    Console.WriteLine($"BIN:         {info.Bin}");            // "550000"
    Console.WriteLine($"Formatted:   {info.Formatted}");      // "5500 0000 0000 0004"
    Console.WriteLine($"PCI Masked:  {info.Masked}");         // "•••• •••• •••• 0004"
    Console.WriteLine($"Last 4:      {info.LastFourDigits}"); // "0004"
    Console.WriteLine($"Check Digit: {info.CheckDigit}");     // 4
}

4. Luhn Check Digit Calculation & Generator

// Calculate Luhn check digit for a 15-digit Visa prefix
int checkDigit = CreditCardValidator.CalculateCheckDigit("453201511283036"); // 6

// Generate complete 16-digit valid card number
string card = CreditCardValidator.Generate("453201511283036"); // "4532015112830366"
