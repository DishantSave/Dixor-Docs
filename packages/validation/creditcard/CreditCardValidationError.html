CreditCardValidationError

The CreditCardValidationError enum defines failure reasons when evaluating payment cards.

namespace Dixor.Validation.CreditCard;

public enum CreditCardValidationError

Members

Value Name Description
0 None The card satisfies all format, length, network, and Luhn checksum requirements.
1 Null The input string is null.
2 Empty The input string is empty ("").
3 WhiteSpace The input string consists exclusively of whitespace characters.
4 InvalidCharacters The input contains invalid non-numeric characters (characters other than permitted spaces or hyphens).
5 InvalidLength The digit length does not match any valid length for its detected network (or general 12-19 range).
6 InvalidChecksum The card failed the Luhn (mod 10) checksum verification.
7 NetworkNotAllowed The card network is not permitted by AllowedNetworks.
8 UnknownNetwork The IIN prefix could not be identified as any recognized payment network.
9 Expired The card has expired based on current date.
10 InvalidExpiryDate The specified expiration month (1-12) or expiration year is structurally invalid.
11 InvalidCvv The specified CVV/CVC code length is invalid for the card brand (3 digits, or 4 for American Express).
