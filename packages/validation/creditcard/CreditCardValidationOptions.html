CreditCardValidationOptions

The CreditCardValidationOptions class configures delimiter allowances, Luhn verification enforcement, and network restrictions for payment cards.

namespace Dixor.Validation.CreditCard;

public sealed class CreditCardValidationOptions

Properties

Property Type Default Description
AllowDelimiters bool true Allows spaces ( ) and hyphens (-) as grouping separators in the input string.
EnforceLuhnChecksum bool true Enforces the Luhn (mod 10) check digit verification.
RequireKnownNetwork bool true Requires the card's IIN/BIN to match one of the 10 recognized payment networks.
AllowedNetworks IReadOnlySet<CardNetwork>? null Optional whitelist of permitted card networks. When null, all networks are allowed.
