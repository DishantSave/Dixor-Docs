Filtering by Network

You can restrict validation to specific authorized card networks using CreditCardValidationOptions.AllowedNetworks:

var options = new CreditCardValidationOptions
{
    AllowedNetworks = new HashSet<CardNetwork>
    {
        CardNetwork.Visa,
        CardNetwork.Mastercard,
        CardNetwork.RuPay
    }
};

bool isValid = CreditCardValidator.IsValid(amexNumber, options); // false (NetworkNotAllowed)
