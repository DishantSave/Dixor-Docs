PassportValidationError

PassportValidationError is an enumeration of all potential validation failure reasons for passport numbers.

Error Values

Name Value Description
None 0 The passport number is valid and meets all constraints.
Null 1 The input string is null.
Empty 2 The input string is empty ("").
WhiteSpace 3 The input contains only whitespace characters.
InvalidCharacters 4 The passport contains non-alphanumeric or disallowed characters.
InvalidLength 5 The passport length violates global ICAO bounds (6 to 12) or country limits.
InvalidFormat 6 The passport does not match the national regex pattern.
CountryNotSupported 7 The specified country ISO or name is not recognized.
CountryNotAllowed 8 The issuing country is not in the allowed list.
CountryBlocked 9 The issuing country is in the blocked list.
Expired 10 The passport has expired based on the expiry date.
NotYetValid 11 The issue date is in the future.
InvalidDateRange 12 The issue date is chronologically after the expiry date.
InsufficientValidity 13 The remaining validity is less than the required minimum (e.g. 6 months).
