PassportValidationOptions

PassportValidationOptions provides fine-grained control over parsing rules, country restrictions, and date constraints.

Properties

Property Type Default Description
DefaultCountryIso string? System Region (e.g. "IN", "US") Fallback ISO-2 or ISO-3 country code when country is not explicitly provided.
StrictCountryRules bool true When true, enforces country-specific regex rules. When false, validates against general ICAO Doc 9303 standards.
AllowSpecialCharacters bool true When true, allows spaces, dashes, dots, and slashes as structural separators.
AllowedCountryIsos ISet<string>? null Whitelist of permitted ISO codes. Numbers from other countries are rejected.
BlockedCountryIsos ISet<string>? null Blacklist of disallowed ISO codes.
RequireMinimumValidity bool true Enforces minimum remaining months when checking expiry dates.
MinimumValidityMonths int 6 Minimum remaining months before expiration (standard international rule).
ReferenceDate DateOnly? Current UTC Date Base reference date for evaluating expiration and remaining validity.

Example Usage

var options = new PassportValidationOptions
{
    DefaultCountryIso = "IN",
    StrictCountryRules = true,
    AllowSpecialCharacters = true,
    RequireMinimumValidity = true,
    MinimumValidityMonths = 6,
    AllowedCountryIsos = new HashSet<string>(StringComparer.OrdinalIgnoreCase) { "IN", "US", "GB", "CA" }
};

var result = PassportValidator.Validate("A1234567", options: options);
