PassportValidator

The PassportValidator static class is the primary entry point for passport number validation, parsing, normalization, and country rule checks.

Namespace

using Dixor.Validation.Passport;

Static Methods

Validation

IsValid(string? passportNumber, string? countryIso = null, PassportValidationOptions? options = null)

Returns true if the passport number is valid for the specified or default country.

bool valid = PassportValidator.IsValid("A1234567", "IN");

IsValid(string? passportNumber, DateOnly expiryDate, string? countryIso = null, PassportValidationOptions? options = null)

Returns true if the passport number is syntactically valid and has not expired.

Validate(string? passportNumber, string? countryIso = null, PassportValidationOptions? options = null)

Performs comprehensive validation and returns a ValidationResult<PassportValidationError>.

ValidationResult<PassportValidationError> result = PassportValidator.Validate("A1234567", "IN");
if (result.IsValid)
{
    // Passed
}

Validate(string? passportNumber, DateOnly? issueDate, DateOnly? expiryDate, string? countryIso = null, PassportValidationOptions? options = null)

Validates syntax, issue date (not in future, not after expiry), and expiration date with minimum validity checks.

Information Retrieval

TryGetInfo(string? passportNumber, out PassportInfo? info, string? countryIso = null, PassportValidationOptions? options = null)

Attempts to parse and return structured passport intelligence without throwing exceptions.

GetInfo(string passportNumber, string? countryIso = null, PassportValidationOptions? options = null)

Returns structured PassportInfo. Throws FormatException if the passport number is invalid.

Normalization & Comparison

Normalize(string passportNumber)

Strips structural separators (spaces, hyphens, periods) and converts all characters to uppercase.

string clean = PassportValidator.Normalize(" a-1234-567 "); // "A1234567"

AreEqual(string? first, string? second)

Compares two passport numbers for normalized equivalence.

bool same = PassportValidator.AreEqual("A-1234-567", "a1234567"); // true

IsValidForCountry(string? passportNumber, string countryIso, PassportValidationOptions? options = null)

Tests whether a passport matches the explicit syntax of a specific country.

GetSupportedCountries()

Returns a list of all 60+ registered country passport rules.
