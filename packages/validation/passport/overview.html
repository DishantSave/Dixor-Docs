Passport Number Validation Overview

Dixor.Validation.Passport provides high-performance, offline validation and intelligence for international passport numbers. It conforms to the ICAO Doc 9303 standard for Machine Readable Travel Documents (MRTD) and incorporates national syntax rules for 60+ countries worldwide.

Key Features

  • ICAO Doc 9303 Compliance: Enforces international standard alphanumeric formats (6 to 9 characters) with extended national support up to 12 characters.
  • 60+ Country Rules: Real-world passport patterns for India, United States, United Kingdom, Canada, Australia, Germany, France, Japan, Singapore, UAE, and dozens more.
  • Date & Travel Validity: Evaluates issue dates, expiration dates, and enforces the standard international 6-month remaining validity rule.
  • Delimiter Tolerance: Intelligently strips visual delimiters (spaces, hyphens, periods) while validating normalized uppercase representations.
  • Zero Third-Party Dependencies: Pure BCL implementation with internal Dependency Injection and sub-microsecond validation throughput.

Quick Start

Basic Validation

using Dixor.Validation.Passport;

// Validate with explicit country ISO (India: 1 letter + 7 digits)
bool isValidIndia = PassportValidator.IsValid("A1234567", "IN"); // true

// Validate US NextGen passport (1 letter + 8 digits)
bool isValidUS = PassportValidator.IsValid("C01234567", "US"); // true

// Validate UK passport (9 digits)
bool isValidUK = PassportValidator.IsValid("123456789", "GB"); // true

Detailed Validation Result

var result = PassportValidator.Validate("A1234#567", "IN");

if (!result.IsValid)
{
    Console.WriteLine($"Validation failed: {result.Error}");
    // Outputs: Validation failed: InvalidCharacters
}

Expiry and Travel Validity Check

DateOnly issue = new(2018, 5, 1);
DateOnly expiry = new(2028, 5, 1);

var result = PassportValidator.Validate(
    "A1234567",
    issueDate: issue,
    expiryDate: expiry,
    countryIso: "IN");

if (result.IsValid)
{
    PassportInfo info = PassportValidator.GetInfo("A1234567", issue, expiry, "IN");
    Console.WriteLine($"Country: {info.CountryName}");
    Console.WriteLine($"Remaining Validity: {info.MonthsUntilExpiry} months");
    Console.WriteLine($"Has >= 6 Months Validity: {info.HasMinimumValidity}");
}
