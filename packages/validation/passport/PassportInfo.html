PassportInfo

PassportInfo is an immutable, thread-safe model encapsulating structured intelligence and breakdown for a validated passport.

Properties

Property Type Description
RawInput string The original raw input string provided to the validator.
NormalizedNumber string Normalized uppercase alphanumeric string without separators.
CountryIso2 string? Two-letter ISO 3166-1 alpha-2 country code (e.g. "IN").
CountryIso3 string? Three-letter ISO 3166-1 alpha-3 country code (e.g. "IND").
CountryName string? Common English name of the issuing nation.
Rule PassportCountryRule? Country-specific rule matched for this passport.
IsStandardIcao9303 bool true if length is between 6 and 9 characters.
IsValid bool true if the number satisfies all validation constraints.
IssueDate DateOnly? Parsed issue date, if evaluated.
ExpiryDate DateOnly? Parsed expiry date, if evaluated.
MonthsUntilExpiry double? Remaining validity in months from the reference date.
IsExpired bool? true if the expiry date has passed; otherwise, false.
HasMinimumValidity bool? true if remaining validity meets the configured minimum threshold (e.g., ≥ 6 months).
