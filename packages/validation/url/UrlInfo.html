UrlInfo

The UrlInfo class encapsulates parsed components, canonical URL formats, and security classification flags.

namespace Dixor.Validation.Url;

public sealed class UrlInfo

Properties

Property Type Description
RawInput string The original raw input string provided to the validator.
NormalizedUrl string The canonical normalized URL string.
Scheme string The protocol scheme in lowercase (e.g. "https").
Host string The host or domain in lowercase (e.g. "api.example.com").
Port int The destination port number.
Path string The hierarchical path component.
Query string The query string (including leading ?), or empty.
Fragment string The fragment/hash identifier (including #), or empty.
IsHttps bool Indicates whether the URL uses HTTPS.
IsIpAddress bool Indicates whether the host is a raw IP literal.
IsPrivateIp bool Indicates whether the host resides in a private, link-local, or reserved IP range.
IsLocalhost bool Indicates whether the host is a loopback or localhost address.
HasCredentials bool Indicates whether user authentication credentials were embedded in the authority.
IsValid bool Indicates whether the URL satisfies all validation constraints.
