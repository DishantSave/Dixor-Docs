UrlValidationError

The UrlValidationError enum defines failure reasons when validating a URL or URI.

namespace Dixor.Validation.Url;

public enum UrlValidationError

Members

Value Name Description
0 None The URL satisfies all syntax and security constraints.
1 Null The input string is null.
2 Empty The input string is empty ("").
3 WhiteSpace The input string consists exclusively of whitespace characters.
4 InvalidFormat The URL string violates RFC 3986 syntax rules.
5 MissingScheme The URL does not specify a protocol scheme (e.g. https://).
6 DisallowedScheme The protocol scheme is not in AllowedSchemes.
7 RequiresHttps The URL uses an insecure scheme when RequireHttps is enabled.
8 MissingHost The URL does not specify a valid host or domain name.
9 LocalhostNotAllowed The host is a loopback or localhost address when AllowLocalhost is false.
10 PrivateIpNotAllowed The host resolves to a private or link-local IP (SSRF defense).
11 IpAddressNotAllowed The host is an IP address literal when AllowIpAddress is false.
12 DisallowedPort The port number is not in AllowedPorts.
13 CredentialsNotAllowed The URL contains embedded credentials (user:pass@host).
14 MissingTld The domain name lacks a valid Top-Level Domain suffix.
