UrlValidator API Reference

The UrlValidator class provides static methods for validating, parsing, normalizing, and verifying the security of URLs and URIs.

namespace Dixor.Validation.Url;

public static class UrlValidator

Methods

IsValid

Determines whether the specified string is a syntactically valid and security-compliant URL.

public static bool IsValid(
    string? url, 
    UrlValidationOptions? options = null);

Example

bool valid = UrlValidator.IsValid("https://example.com"); // true
bool ssrf = UrlValidator.IsValid("http://192.168.1.1");    // false (Private IP blocked)

Validate

Validates a URL and returns a structured ValidationResult<UrlValidationError> indicating validity or exact failure diagnostic.

public static ValidationResult<UrlValidationError> Validate(
    string? url, 
    UrlValidationOptions? options = null);

Example

var result = UrlValidator.Validate("https://user:password@example.com");
if (!result.IsValid)
{
    Console.WriteLine($"Error: {result.Error}"); // CredentialsNotAllowed
}

TryGetInfo and GetInfo

Parses the URL into a structured UrlInfo record containing components, canonical forms, and security flags.

public static bool TryGetInfo(
    string? url, 
    out UrlInfo? info, 
    UrlValidationOptions? options = null);

public static UrlInfo GetInfo(
    string url, 
    UrlValidationOptions? options = null);

Normalize and TryNormalize

Canonicalizes the URL by converting scheme and host to lowercase, stripping default ports (:80, :443), and standardizing paths.

public static string Normalize(string url);
public static bool TryNormalize(string? url, out string? normalized);

Example

string clean = UrlValidator.Normalize("HTTPS://EXAMPLE.COM:443/products/");
// "https://example.com/products/"

AreEqual

Determines whether two URL representations resolve to the identical canonical destination.

public static bool AreEqual(string? first, string? second);
