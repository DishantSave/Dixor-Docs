UrlValidationOptions

The UrlValidationOptions class configures validation strictness, protocol scheme whitelisting, and SSRF security policies.

namespace Dixor.Validation.Url;

public sealed class UrlValidationOptions

Properties

Property Type Default Description
AllowedSchemes IReadOnlySet<string> ["http", "https"] Permitted URL schemes.
RequireHttps bool false When true, URLs using plain http:// or other insecure schemes are rejected.
AllowLocalhost bool false When false, requests to localhost, 127.0.0.1, and ::1 are blocked (SSRF defense).
AllowPrivateIps bool false When false, requests to RFC 1918 private subnets and link-local ranges are blocked (SSRF defense).
AllowIpAddress bool true Allows raw IP literals (e.g. 8.8.8.8). When false, only named domains are allowed.
AllowCredentials bool false When false, URLs containing embedded credentials (user:pass@host) are blocked.
RequireTld bool true Mandates that named domains possess a valid Top-Level Domain suffix.
AllowedPorts IReadOnlySet<int>? null Optional whitelist of permitted destination port numbers.
