Dixor.Validation Changelog

All notable changes to the Dixor.Validation package are documented in this file.

The format is based on Keep a Changelog, and this project adheres strictly to Semantic Versioning.

[0.1.1] — 2026-11-22

Added

  • International Phone & Contact Validation: Comprehensive E.164 phone number normalization, national/international formatting, telecom carrier/circle metadata detection, line classification (Mobile, FixedLine, TollFree, VoIP), and contact equality comparison (PhoneValidator, ContactValidator).
  • Passport Verification (ICAO Doc 9303): Machine-readable travel document (MRTD) and national passport validation for 60+ countries with date-of-birth, expiry, and 6-month validity checking (PassportValidator).
  • Address & Postal Code Validation: ISO 3166-1 alpha-2/3 country codes, ISO 3166-2 state/province subdivisions, and postal/ZIP code format validation (AddressValidator).
  • Aadhaar Identity Validation: Indian 12-digit UIDAI identity number validation powered by the dihedral group \(D_5\) Verhoeff checksum algorithm, normalization, and data privacy masking (AadhaarValidator).
  • Payment Card Validation: High-speed Luhn mod-10 checksum calculation, IIN/BIN network classification across 10 major global brands (Visa, Mastercard, Amex, Discover, RuPay, JCB, Diners Club, UnionPay, Maestro, Mir), CVV/expiry checking, and PCI-DSS masking (CreditCardValidator).
  • URL/URI Validation with SSRF Defense: RFC 3986 compliant URI syntax parsing with protection against SSRF attacks (blocking loopback, IPv4/IPv6 private subnets, and AWS/cloud metadata) (UrlValidator).
  • Dixor.DI Integration: 1-line service registration via services.AddDixorValidation().

[0.1.0] — 2026-07-04

Added

  • Email Validation Engine: Initial release of the state-machine email validation engine built without regular expressions to eliminate ReDoS vulnerabilities and reduce heap allocations.
  • Structured Diagnostics: Strongly typed error reporting (EmailValidationError) covering local-part syntax, domain labeling, consecutive dots, and illegal characters.
  • Suggestion Engine: Algorithmic domain correction engine that detects common mobile registration typos (e.g., suggesting gmail.com for inputs like gmai.com).
  • Parsing & Inspection: Dedicated APIs (EmailParser.Parse()) to safely extract and inspect structural email components (LocalPart, Domain).
