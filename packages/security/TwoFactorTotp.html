Two-Factor Authentication (TOTP / RFC 6238)

The ITotpService provides full support for Time-based One-Time Passwords (TOTP / RFC 6238), the global standard for multi-factor authentication (MFA) supported by Google Authenticator, Microsoft Authenticator, 1Password, and Authy.

How TOTP Works

  1. Secret Key Provisioning: When a user enables 2FA, the server generates a cryptographically secure Base32 secret key (e.g. JBSWY3DPEHPK3PXP) and displays it as a QR code.
  2. Authenticator App Sync: The user scans the QR code with their mobile authenticator app.
  3. Passcode Generation: Every 30 seconds, both server and phone independently compute an identical 6-digit numeric passcode based on the current Unix timestamp: \(T = \lfloor \frac{\text{unixTime}}{30} \rfloor\)
  4. Passcode Verification: The user inputs the 6-digit passcode. The server verifies it with clock drift tolerance (\(\pm 30\) seconds).

Step-by-Step Implementation Guide

Step 1: Provisioning 2FA for a User

[ApiController]
[Route("api/2fa")]
public class TwoFactorController(ITotpService totpService) : ControllerBase
{
    [HttpPost("setup")]
    public IActionResult SetupTwoFactor([FromQuery] string email)
    {
        // 1. Generate a new cryptographically secure Base32 secret:
        string secretKey = totpService.GenerateSecretKey(); // e.g. "JBSWY3DPEHPK3PXP..."

        // 2. Generate standard otpauth:// QR URI:
        string qrUri = totpService.GenerateQrCodeUri(
            secretKey: secretKey,
            accountName: email,
            issuer: "Dixor Enterprise");

        // 3. Save secretKey to database (encrypted with IDataEncryptor!):
        // user.EncryptedTotpSecret = dataEncryptor.Encrypt(secretKey, masterKey);
        // await db.SaveChangesAsync();

        return Ok(new
        {
            SecretKey = secretKey,
            QrCodeUri = qrUri // Render this URI into a QR code using any SVG/PNG renderer
        });
    }
}

The resulting QR URI matches standard RFC format:

otpauth://totp/Dixor%20Enterprise:alice%40example.com?secret=JBSWY3DPEHPK3PXP&issuer=Dixor%20Enterprise&algorithm=SHA1&digits=6&period=30

Step 2: Validating Passcodes on Login

When a user submits their 6-digit code during two-factor login:

[HttpPost("verify")]
public IActionResult VerifyCode([FromBody] VerifyTwoFactorDto dto)
{
    // 1. Fetch user's decrypted secret key from database:
    string userSecretKey = "JBSWY3DPEHPK3PXP";

    // 2. Validate passcode with 1-step (+/- 30s) clock drift tolerance:
    bool isValid = totpService.ValidateCode(
        secretKey: userSecretKey,
        code: dto.Passcode, // e.g. "482910"
        allowedDriftSteps: 1, // Checks T-1, T, T+1
        digits: 6,
        periodSeconds: 30);

    if (!isValid)
    {
        return Unauthorized(new { Error = "Invalid or expired two-factor authentication passcode." });
    }

    return Ok(new { Message = "Two-factor authentication successful." });
}

Step 3: Checking Time-Step Expiration Countdown

To display a countdown progress wheel (like in authenticator apps and the Dixor.Studio):

// Returns remaining seconds (1 to 30) before the current passcode changes
int secondsLeft = totpService.GetRemainingSeconds();

Security Best Practices for 2FA

  1. Encrypt Secret Keys in the Database: Never store raw Base32 TOTP secrets in plaintext. Always encrypt them using IDataEncryptor.
  2. Prevent Code Reuse: After a code is accepted, record the used time step (\(T\)) in memory or cache for 60 seconds to prevent replay attacks within the same 30-second window.
  3. Rate Limiting: Enforce a maximum of 5 failed 2FA attempts per minute to block automated brute-force attacks on 6-digit codes.
