Dixor.Security Documentation

Dixor.Security is a high-performance, production-grade cryptography, authentication, and data protection library built natively for modern .NET 8, .NET 9, and .NET 10.

Overview

Modern cloud systems and enterprise microservices face demanding security challenges:

  • Credential plumbing: Storing and transporting user session state securely.
  • Authentication: Issuing reversible authenticated tokens, API client secrets, and OAuth2 Bearer tokens.
  • Data protection: Encrypting sensitive database fields (PII, financial records) with authenticated AEAD ciphers.
  • Searchable encryption: Querying encrypted database records without decrypting them (blind indexing).
  • MFA & Access: Generating Time-based One-Time Passwords (TOTP RFC 6238) for Google and Microsoft Authenticator.
  • Audit compliance: Preventing timing attacks and masking sensitive data in log streams.

Dixor.Security provides intuitive, developer-friendly abstractions with battle-tested NIST-approved cryptographic primitives, eliminating the footguns and complexities of manual cryptography.

// Program.cs - 1 line bootstrap via Dixor.DI
builder.Services.AddDixor();

// Or standalone registration
builder.Services.AddDixorSecurity();

Core Capabilities

  • Reversible Authenticated Tokens (IAuthTokenService): Issue encrypted tokens carrying Name, Password, and Custom Data that can be safely reverse-decoded and extracted by authorized services using AES-256-GCM.
  • Client Secret & Public Key Authentication (IClientCredentialService): Generate secure Client ID and Client Secret pairs with PBKDF2 hashing, and provision asymmetric RSA (2048/4096) or ECDSA (NIST P-256) key pairs with PEM export and digital signature verification.
  • OAuth2 Bearer Tokens (IOAuth2TokenService): Issue and validate RFC 6749 / RFC 7519 JSON Web Tokens (JWT) signed with HMAC-SHA256, supporting scopes, custom claims, and high-entropy refresh tokens.
  • Key-Based Data Encryption (IDataEncryptor): NIST SP 800-38D AES-256-GCM authenticated encryption with 96-bit random nonces, 128-bit authentication tags, and optional Associated Data (AAD) binding.
  • Deterministic One-Way Keyed Hashing (IDeterministicHasher): HMAC-SHA256 and HMAC-SHA512 hashing guaranteeing that identical input with the same key always produces the exact same hash for database blind indexing.
  • PBKDF2 Password Hashing (IPasswordHasher): Cryptographically salted password hashing (100,000 iterations default) with constant-time equality checks and rehash detection.
  • Two-Factor Authentication (ITotpService): RFC 6238 Time-based One-Time Password generator and validator compatible with Google Authenticator, Microsoft Authenticator, and 1Password.
  • Prefixed API Keys (IApiKeyService): Generate high-entropy, environment-prefixed API keys (dx_live_..., dx_test_...) with SHA-256 database storage.
  • Sensitive Data Masking (ISensitiveDataMasker): Cleanly mask credit cards, email addresses, and API secrets prior to writing to audit logs or telemetry.
  • Constant-Time Verification (CryptographicUtils): Timing-safe equality operations (FixedTimeEquals) to neutralize side-channel timing attacks.
