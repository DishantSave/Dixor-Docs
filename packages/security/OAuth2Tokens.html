OAuth2 Bearer Token Generation & Validation

IOAuth2TokenService provides standard OAuth2 (RFC 6749) Bearer Access Token generation, cryptographic HMAC-SHA256 signing, payload claim validation, and high-entropy refresh token issuance.

Architecture

OAuth2 tokens generated by Dixor.Security follow the JSON Web Token (JWT / RFC 7519) compact format: \(\text{AccessToken} = \text{Base64Url}(\text{Header}) \ . \ \text{Base64Url}(\text{Payload}) \ . \ \text{Base64Url}(\text{Signature})\)

  • Header: {"alg":"HS256","typ":"JWT"}
  • Payload: Contains standard registered claims (iss, sub, aud, client_id, scope, iat, exp, jti) alongside arbitrary custom domain claims.
  • Signature: \(\text{HMAC-SHA256}(SigningKey, Header.Payload)\)

Step-by-Step Implementation Guide

Step 1: Issue Tokens from your /token Endpoint

Create an OAuth2 token endpoint compliant with standard authorization server flows:

[ApiController]
[Route("connect/token")]
public class OAuthTokenController(IOAuth2TokenService oauthService, IConfiguration config) : ControllerBase
{
    private readonly string _signingKey = config["OAuth:SigningKey"] 
        ?? "MySecureHMACSHA256SecretSigningKeyForTokens!#";

    [HttpPost]
    public IActionResult IssueToken([FromForm] TokenEndpointRequest form)
    {
        // 1. Validate grant_type, client credentials, or user password...

        // 2. Define token request:
        var request = new OAuth2TokenRequest
        {
            ClientId = form.ClientId ?? "mobile_app",
            Subject = "usr_10203040", // User ID
            Audience = "https://api.myapp.com/v1",
            Scopes = ["read:profile", "write:orders", "payment:process"],
            Claims = new Dictionary<string, string>
            {
                ["tenant_id"] = "tenant_us_east",
                ["tier"] = "Enterprise",
                ["email"] = "alice@example.com"
            },
            Lifetime = TimeSpan.FromHours(1),
            IssueRefreshToken = true
        };

        // 3. Issue OAuth2 token response:
        OAuth2TokenResponse response = oauthService.GenerateToken(request, _signingKey);

        return Ok(new
        {
            access_token = response.AccessToken,
            token_type = response.TokenType, // "Bearer"
            expires_in = response.ExpiresIn,   // 3600
            refresh_token = response.RefreshToken,
            scope = response.Scope
        });
    }
}

Step 2: Validate Bearer Tokens in Downstream APIs

When requests hit protected API endpoints with an Authorization: Bearer <token> header:

[ApiController]
[Route("api/secure-data")]
public class SecureDataController(IOAuth2TokenService oauthService, IConfiguration config) : ControllerBase
{
    private readonly string _signingKey = config["OAuth:SigningKey"]!;

    [HttpGet]
    public IActionResult GetData()
    {
        // 1. Extract Bearer token from Authorization header:
        string? authHeader = Request.Headers.Authorization.FirstOrDefault();
        if (string.IsNullOrEmpty(authHeader) || !authHeader.StartsWith("Bearer ", StringComparison.OrdinalIgnoreCase))
        {
            return Unauthorized(new { Error = "Missing or malformed Authorization header." });
        }

        string token = authHeader["Bearer ".Length..].Trim();

        // 2. Validate token signature and expiration:
        OAuth2TokenValidationResult result = oauthService.ValidateAccessToken(token, _signingKey);

        if (!result.IsValid)
        {
            return Unauthorized(new { Error = result.Error });
        }

        // 3. Access validated identity, scopes, and claims:
        string userId = result.Subject!;
        string clientId = result.ClientId!;
        string tier = result.Claims["tier"];
        bool canWrite = result.Scopes.Contains("write:orders");

        return Ok(new
        {
            UserId = userId,
            ClientId = clientId,
            SubscriptionTier = tier,
            AllowedScopes = result.Scopes,
            ExpiresAt = result.ExpiresAt
        });
    }
}

Step 3: Refresh Token Issuance & Rotation

IOAuth2TokenService.GenerateRefreshToken() generates a secure, cryptographically random string with prefix dx_rt_:

// Generates: dx_rt_9f8a7b6c5d4e3f2a1b0c9d8e7f6a5b4c3d2e1f0a
string newRefreshToken = oauthService.GenerateRefreshToken("dx_rt");
