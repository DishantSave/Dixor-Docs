Prefixed API Keys & Sensitive Data Masking

This guide covers two essential utilities in Dixor.Security:

  1. Prefixed API Keys (IApiKeyService): Generating high-entropy API tokens formatted like modern cloud providers (dx_live_..., dx_test_...) with secure SHA-256 database hashing.
  2. Sensitive Data Masking (ISensitiveDataMasker): Redacting credit cards, emails, tokens, and secrets before outputting to log streams, telemetry, or error messages for PCI-DSS, GDPR, and SOC 2 compliance.

1. Prefixed API Keys (IApiKeyService)

Modern API platforms (such as Stripe, GitHub, and OpenAI) prefix their API tokens so that developers and automated secret scanners (like GitHub Secret Scanning) can immediately detect leaked keys.

Step 1: Issuing an API Key

[ApiController]
[Route("api/keys")]
public class ApiKeyController(IApiKeyService apiKeyService) : ControllerBase
{
    [HttpPost("generate")]
    public IActionResult GenerateKey([FromQuery] string environment = "live")
    {
        string prefix = environment == "live" ? "dx_live" : "dx_test";

        // Generates 256 bits of entropy:
        ApiKeyResult result = apiKeyService.GenerateApiKey(prefix, entropyBytes: 32);

        // 1. Save HashedKey to your database:

        //     CreatedAt = result.CreatedAt
        // });
        // await db.SaveChangesAsync();

        // 2. Return PlaintextKey to user ONCE:
        return Ok(new
        {
            Key = result.PlaintextKey,  // e.g. "dx_live_8f3a9e2b1c4d..."
            Hint = result.KeyHint,      // e.g. "dx_live_8f3a..."
            Warning = "Store this API key safely. It will not be shown again."
        });
    }
}

2. Sensitive Data Masking for Logs (ISensitiveDataMasker)

Accidental exposure of PII, credit card numbers, or auth tokens in application log files is a major cause of security breaches and regulatory non-compliance. ISensitiveDataMasker guarantees safe redaction across all loggers.

Masking Credit Cards (PCI-DSS)

Preserves only the final 4 digits, replacing all other digits with asterisks:

string masked = masker.MaskCreditCard("4532 7521 8934 1234");
// Output: "************1234"

Masking Email Addresses (GDPR)

Preserves the first 2 characters of the local part and the domain name, masking everything in between:

string masked = masker.MaskEmail("dishantsave@example.com");
// Output: "di****@example.com"

Masking API Keys and Secrets

Masks the middle of the secret, preserving a configurable prefix and suffix:

string masked = masker.MaskSecret("dx_sec_88f9e0a1b2c3d4e5f6a7b8c9d0e1", visiblePrefix: 4, visibleSuffix: 4);
// Output: "dx_s****...****d0e1"

Generic Masking

string masked = masker.MaskGeneric("SensitiveAccountToken123", prefixLen: 3, suffixLen: 3);
// Output: "Sen****************123"

Log Enrichment Example

Use masking in Serilog or standard ASP.NET Core loggers:

logger.LogInformation(
    "Processing payment for card {Card} and email {Email}",
    masker.MaskCreditCard(order.CardNumber),
    masker.MaskEmail(order.CustomerEmail));

Logs will safely read:

[12:00:00 INF] Processing payment for card ************1234 and email jo****@domain.com
