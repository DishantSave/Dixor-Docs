[0.1.0] — 2026-11-22

Added

  • Reversible Authentication Tokens (AuthTokenService): High-performance reversible authentication token issuance and verification engine embedding identity credentials and custom claims using AES-256 authenticated encryption (IAuthTokenService).
  • Authenticated Data Encryption (DataEncryptor): NIST standard AES-256-GCM AEAD encryption engine with 128-bit authentication tag verification and Associated Authenticated Data (AAD) support. Includes zero-dependency pure C# managed AES fallback (ManagedAes) ensuring 100% bit-for-bit compatibility across WebAssembly and Server runtimes without throwing PlatformNotSupportedException.
  • API Client Credentials & Asymmetric Keys (ClientCredentialService): Automated client ID and secure secret generation with PBKDF2-SHA256 salted hashing. Generates RSA (2048/4096-bit) and ECDSA (P-256) public/private key pairs with PEM export and digital signature creation/verification (IClientCredentialService).
  • OAuth2 Bearer Tokens (OAuth2TokenService): RFC 6749 and RFC 7519 compliant JSON Web Token (JWT) Bearer access token and refresh token generation, HMAC-SHA256 digital signing, payload claims serialization, and expiration validation (IOAuth2TokenService).
  • Deterministic Blind Indexing (DeterministicHasher): Keyed one-way deterministic hashing powered by HMAC-SHA256 and HMAC-SHA512 with constant-time equality validation for secure, encrypted database lookups (IDeterministicHasher).
  • PBKDF2 Password Hashing (PasswordHasher): Salted password hashing complying with RFC 2898 / RFC 8018 with 100,000 iterations of PBKDF2-SHA256, 128-bit CSPRNG salt, and constant-time verification (IPasswordHasher).
  • Two-Factor Authentication (TotpService): RFC 6238 Time-based One-Time Password (TOTP) and RFC 4226 HMAC-based One-Time Password (HOTP) generator and validator with Base32 secret generation, drift-step tolerance, and standard otpauth:// QR code URI formatting (ITotpService).
  • Prefixed API Keys & Constant-Time Validation (ApiKeyService): Enterprise-grade CSPRNG prefixed API key generator with SHA-256 database digest generation and timing-attack-proof validation (IApiKeyService).
  • Sensitive Data Masking (SensitiveDataMasker): PCI-DSS and GDPR compliant data masking routines for credit cards, email addresses, phone numbers, Aadhaar numbers, tax IDs, and secret tokens (ISensitiveDataMasker).
  • Dependency Injection Integration: 1-line service registration via services.AddDixorSecurity() registering all security abstractions into the DI container.
