Remarks

Features:

  • Full RFC 3986 syntax and structure compliance.
  • Scheme verification (HTTP, HTTPS, FTP, WebSocket, custom whitelist).
  • Security hardening against SSRF: automatic blocking of localhost, loopback, and private IPv4/IPv6 ranges.
  • Credential detection (flags URLs with embedded usernames/passwords).
  • Canonical URL normalization (lowercasing, default port removal, trailing slash handling).
  • Top-Level Domain (TLD) enforcement.
