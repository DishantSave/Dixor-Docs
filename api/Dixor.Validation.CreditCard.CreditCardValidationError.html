Specifies the failure reasons when validating a credit, debit, or payment card.

public enum CreditCardValidationError

Fields

Empty = 2

The input string is empty.

Expired = 9

The card has expired based on the specified expiration month and year.

InvalidCharacters = 4

The input contains invalid non-numeric characters (other than permitted spaces or hyphens).

InvalidChecksum = 6

The card number failed the Luhn (mod 10) algorithm checksum verification.

InvalidCvv = 11

The specified CVV/CVC code is invalid for the card network (3 digits, or 4 digits for American Express).

InvalidExpiryDate = 10

The specified expiration month (1-12) or expiration year is structurally invalid.

InvalidLength = 5

The card number length does not match any valid length for its detected network (or general card standard 12-19 digits).

NetworkNotAllowed = 7

The card's IIN prefix corresponds to a network that is not permitted by validation options.

None = 0

The card number satisfies all format, length, network, and Luhn checksum requirements.

Null = 1

The input string is null.

UnknownNetwork = 8

The card network could not be identified from the leading IIN/BIN prefix.

WhiteSpace = 3

The input string consists exclusively of whitespace characters.
