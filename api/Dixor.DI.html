IDixorContextAccessor<TContext>

Provides access to ambient runtime context flowed down asynchronous call chains and dependency injection trees without requiring explicit constructor argument passing through intermediate layers.

Defines a parameterized activation factory that instantiates TService by resolving standard dependencies from the DI container while accepting a dynamic runtime constructor argument.

Defines a parameterized activation factory accepting two dynamic runtime constructor arguments.

IDixorModule

Defines a modular contract for encapsulating and registering related services into an IServiceCollection.

Provides a unified, type-safe mechanism to resolve specific implementations when multiple classes implement the same service contract, supporting keyed lookup, default resolution, and collection iteration.
