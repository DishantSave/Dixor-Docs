Remarks

Features:

  • Hardware-accelerated Luhn (mod 10) checksum verification.
  • Comprehensive IIN/BIN card network identification (Visa, Mastercard, American Express, Discover, RuPay, JCB, Diners Club, Maestro, UnionPay, Mir).
  • Network-specific valid length constraints and digit grouping conventions.
  • Expiration date analysis (future validity, expired checks, month/year boundaries).
  • CVV/CVC length validation (3 digits, or 4 digits for American Express).
  • PCI-DSS privacy masking (e.g. •••• •••• •••• 1234).
