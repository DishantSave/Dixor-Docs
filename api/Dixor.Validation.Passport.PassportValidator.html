Remarks

PassportValidator provides comprehensive compliance checks against international ICAO Doc 9303 standards and country-specific national passport numbering rules for over 60 countries.

It supports syntax validation, uppercase normalization, country matching, expiry and issue date evaluation, and the standard 6-month international remaining validity check.
