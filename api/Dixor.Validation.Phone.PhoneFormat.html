Enum PhoneFormat

Namespace
Dixor.Validation.Phone
Assembly

Specifies the formatting style applied to a telephone number.

public enum PhoneFormat

Fields

E164 = 0

Formats the number as an unspaced canonical E.164 string with a leading plus sign (e.g., +12025550123).

International = 1

Formats the number in international representation with country code and grouped national digits (e.g., +1 202 555 0123).

National = 2

Formats the number in national representation using the country's national trunk prefix and delimiters (e.g., (202) 555-0123 or 020 7946 0919).

Rfc3966 = 3

Formats the number according to the RFC 3966 tel: URI specification (e.g., tel:+1-202-555-0123).
