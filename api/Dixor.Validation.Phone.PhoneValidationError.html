Remarks

PhoneValidationError provides a strongly typed set of error codes returned by the phone number validation pipeline. Each member represents a specific validation failure encountered while parsing or validating a phone number.

When validation succeeds, None is returned. Otherwise, one of the remaining members identifies the exact reason the phone number failed validation.

These values are intended to be consumed by ValidationResult<TError> to provide deterministic, allocation-free error reporting.
