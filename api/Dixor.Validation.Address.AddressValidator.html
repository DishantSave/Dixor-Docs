Remarks

AddressValidator is the primary entry point for address-related validation in Dixor.Validation. It provides full catalog validation for 240+ international country codes (alpha-2, alpha-3, numeric-3), comprehensive state/province/territory subdivisions for major countries (India, US, Canada, Australia, UK, Germany), postal rules for 100+ countries, and composite address consistency checks.
