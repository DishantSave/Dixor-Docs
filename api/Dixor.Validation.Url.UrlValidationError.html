Namespace

Assembly

Specifies the failure reasons when validating a Uniform Resource Locator (URL) or URI.

public enum UrlValidationError

Fields

CredentialsNotAllowed = 13

The URL contains embedded user credentials (e.g. "https://user:pass@host"), which poses a security risk.

DisallowedPort = 12

The port number is not in the permitted ports list.

DisallowedScheme = 6

The protocol scheme is not in the list of permitted schemes.

Empty = 2

The input string is empty.

InvalidFormat = 4

The URL string is malformed or violates RFC 3986 syntax rules.

IpAddressNotAllowed = 11

The host is an IP address literal when IP addresses are disallowed.

LocalhostNotAllowed = 9

The host name is a loopback or localhost address when localhost is prohibited.

MissingHost = 8

The URL does not specify a valid host or domain name.

MissingScheme = 5

The URL does not specify a protocol scheme (e.g. "https://").

MissingTld = 14

The domain name lacks a valid Top-Level Domain (TLD) extension.

None = 0

The URL is valid and satisfies all format and security constraints.

Null = 1

The input string is null.

PrivateIpNotAllowed = 10

The host resolves to a private or link-local IP address (SSRF mitigation).

RequiresHttps = 7

The URL is not using the HTTPS scheme when HTTPS is strictly required.

WhiteSpace = 3

The input string consists exclusively of whitespace characters.
