IDeterministicHasher

Defines contracts for deterministic, keyed one-way cryptographic hashing (HMAC-SHA256 and HMAC-SHA512). Guarantees that identical input text with the same secret key always produces the exact same hash digest, enabling safe exact-match database queries (blind indexing) without storing raw plaintext.
